## Only the Plate velocity-loss mapping changed

The unchanged compiler maps immutable birth damping `mu` to:

```
d_compiled = 0.000009 + 0.000018 * mu
mu in [0.25, 0.45]
```

Previously the Plate recurrence used `d_compiled` directly in `-d*(u-u_previous)`. It now uses `d = 50*d_compiled`. The positive multiplier is applied only where the Plate recurrence reads its damping coefficient. No compiler, frozen descriptor, Z spring, Sphere damping, contact mechanism, pickup, gain or limiter is altered.

The old range 0.0000135–0.0000171 becomes 0.000675–0.000855 at the same 6000 Hz physics rate. Equivalently, the loss intercept/slope are 0.00045 and 0.0009. Material ranking and the high/low loss ratio of 1.2667 are preserved. This is a dimensionless linear solver, not a calibrated soil loss model.

The multiplier was selected after observing roughly 50 s to -20 dB, aiming for roughly 1 s to -20 dB and a few seconds of ringing. It is a single common velocity-loss scaling, rather than a fixed identical decay per material. The measured first-Plate T60 is approximately 3 s. Early resonance remains measurable after 150–500 ms; it has not been converted into an impulse-only click. Different geometry and material can still change the envelope.

A separate Node VM engineering check holds that same geometry, pickups and actual foot fixed while cloning only the material bounds. With `mu=0.25`, measured L/R T60 is 3.41 / 3.52 s; with `mu=0.45`, it is 2.71 / 2.74 s. Sleep starts after those crossings. This 2.71–3.52 s range demonstrates preserved material variation; it is not a claim of natural births at those synthetic material bounds or an additional Chrome recording. The target is approximate and was not forced to one identical 3 s duration.

The existing 3 ms half-sine pulse, 75 ms local memory, 0.020 load reference and maximum 25% compliance reduction are unchanged. Every valid contact and route remains counted. There is no additional event gate, input strength change, output normalization, saturation increase or gain compensation.
