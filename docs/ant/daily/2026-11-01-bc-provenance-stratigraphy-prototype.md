# B/C provenance stratigraphy prototype

## Question

If every already-measured B/C shadow maturation event is represented as one immutable provenance layer, what cumulative structure results, and is the unarbitrated stream compatible with the current material architecture's scale?

## Work

- Reused the exact 2,089 registered events and frozen three-seed material/birth anchors; no new world trajectory.
- Built a research-only per-cell ledger with exact X masks, numeric timestamps, track IDs, and source receipts. Exact same-time B/C deposits share a `{B,C}` time group without a physical tie order.
- Produced six-time snapshots, fixed-scale count/provenance maps, actual-material references, event/birth pressure plots, objective episode cases, and representative chronology columns.
- Independently rebuilt the cell/time ledger and verified event masks, 60 s arithmetic, 256-reference crossings, snapshots, objective contexts, and deterministic PNGs.
- No production `src/` or `static/` change, RNG use, Plate creation, or material feedback.

## Result

**COMPLEMENTARY BUT OVERPROLIFIC.** The three streams contain 662, 717, and 710 events, crossing the 256-Plate reference at 272.017, 247.017, and 253.017 s. By 600 s, each grid has 67.7–71.5% coverage, many mixed and exclusive B/C cells, and thousands of strict B→C and C→B transitions. The virtual history remains legible, but direct one-event/one-layer insertion would exceed the current storage scale well before the run ends.

Smallest next question, only if dual provenance remains desired: what separate final commit/arbitration responsibility should map matured episodes into real finite material under current storage and feedback constraints while preserving coeval provenance? This pass does not define it.
