## Logging rule

새 과정 로그는 `YYYY-MM-DD-topic.md` 형식으로 추가한다.

가능하면 다음을 남긴다:

- 출발 질문 / hypothesis
- baseline
- 실제 변경
- evidence / negative result
- 판정
- 남은 한계
- 다음 pass로 넘어간 이유

commit timestamp와 실험 날짜가 다를 수 있으므로, 별도 검증하지 않은 wall-clock chronology를 추정해서 쓰지 않는다.
