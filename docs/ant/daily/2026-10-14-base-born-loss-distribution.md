# 2026-10-14 — Base/Born loss-distribution comparison

Question: with Born's current elastic law, geometry, contact and pickups fixed, does frequency-selective loss differ from flat loss when the real-valued free pole and input gain are matched at `q=4`?

Used the existing isolated single-contact renders and frozen P1/P24/P26 geometry trio. Did not create a natural-run contact archive. Flat arm set `gamma=0, d=dBorn+4*gammaStar`; frequency arm set `gamma=gammaStar, d=dBorn`, with `gammaStar=8*gammaBase48=0.0004929124754306856`. The manipulation asserts identical schedule, topology, elastic/material state except the loss coefficient, pickups and readout. Real-valued q=4 pole/input gain match is exact; Float32 residuals are recorded per plate. The old frequency arm re-rendered byte-identically; flat PCM, field and raw pickup repeats matched exactly.

Decision: **SUPPORTED for response responsibility under this frozen recipe**. All three geometries show slower `q<4` post-pulse decay in the frequency-loss arm, approximately unchanged `q=4`, and faster `q>4`. The fixed-gain stereo pickups preserve a large growing tail difference: 500 ms-to-end RMS changes by `+13.11`, `+20.68`, and `+26.00 dB` for P1/P24/P26, while first-25-ms RMS changes by only `+0.20`, `+0.43`, and `+0.56 dB`. P24 ERB late-tail differences are low/mid/high `+21.90/−3.23/+17.89 dB`; low and high rise across the trio, while the mid-group result varies by geometry. Off-pivot input gain changes by design, so the pickup delta includes onset participation as well as decay; the post-pulse modal slopes are the direct evidence for decay selectivity.

The ERB-binned STFT sidecar adds an easy-to-read time-varying band-tail view, not signal content beyond the existing STFT. It uses 30 equal ERB-rate bands, the existing 1024 Hann / 256 hop / 0–8 kHz axes, aggregates linear power before dB, and stores the boundaries, centers and DC convention. Synthetic tone, silence, same-input, scaling and monotonicity checks passed. It is not a gammatone/cochleogram and does not establish audibility.

No human listening assessment was performed. Fixed-gain measurement WAVs and RMS-matched listening-only WAVs are separately labeled; automatic audibility/preference judgment was not used. Production remains unchanged, including `3 ms / 75 ms / ×50`; no tuning, adoption or follow-up experiment was performed. The p25/p50/p75 common-three-contact sensitivity was not run, so the result stays bounded to the established p50 recipe.

Focused validation: 60/60 tests across the q4 helper, shadow renderer, topology, worklet, bridge and fixed-scale STFT; direct ESM imports were used after `node --test` hit sandbox `spawn EPERM`. The six render rows and prior parity are covered in the [evidence package](../evidence/2026-10-14-base-born-loss-distribution/README.md). Formation/behavior, Base calibration, Z/Nodule, real-time runtime, gammatone and other perceptual measures remain parked.
