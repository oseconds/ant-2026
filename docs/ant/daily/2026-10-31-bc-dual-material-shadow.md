# B/C dual-material shadow maturation

## Question

Do independently tracked qualified chemical history (B) and contact-written compaction (C), under the same 20 s / `.60` X-stability grammar, produce duplicate events or complementary virtual stratigraphy?

## Work

- Reused the frozen three-seed, 599-boundary opportunity histories, exact B/C tracks and registered X sets.
- Emitted 1,135 B and 954 C shadow maturation events using one identical actual-time rule.
- Compared exact and nearest-opposite event timing, X overlap, and a read-only per-cell virtual provenance ledger.
- Reconstructed eight missing selected native renderer frames for case presentation only; no new world-history measurements were used.
- Independently checked all 2,089 event chains, 42,344 adjacent-X transitions and every touched ledger cell; all passed.
- Production `src/` and `static/` remain unchanged. No actual Plate, material feedback, physical/audio distinction, competition, or Residence work.

## Result

**DUAL HISTORY / COMPLEMENTARY.** Timing is closely synchronized (median nearest opposite-event lag 0 s; all events have an opposite-channel event within 20 s), while exact same-boundary X pairs are more often disjoint (693) than identical (581). The virtual ledger contains 14,177 cells touched by both channels plus 3,773 B-only and 1,349 C-only cells. Both strict B→C and C→B sequence orders occur extensively.

This supports considering a later provenance-only dual-material prototype; it does not choose B or C, assign different physical/audio properties, or infer artistic acceptance. Smallest next question: whether to authorize that provenance-only prototype with identical properties.
