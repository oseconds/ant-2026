## Exact observer boundary

At each actual `TrailPlateBirth.advance` analysis call:

1. Production completed its ordinary update of chemical memory and built the current supported E mask and D support values.
2. The observer copied E and D, then ran the exact production `zhangSuen` implementation extracted from the unchanged source to compute `F = thinning(E)`.
3. It selected the edge-bearing F node with maximum D support. The source’s row-major index is the exact tie-break.
4. It formed X as the 8-neighbor component containing that nucleus in `F ∩ EuclideanDisk(nucleus, R=.15)`.
5. It recorded the current production candidate, pre-birth material snapshot, and X. It returned no state to production.

The edge-bearing nucleus, D priority, source-extracted thinning, 8-neighbor topology, and R=.15 were held fixed. The `.30` source→boundary reach gate was not applied to X.

The observer ran after the real production analysis, inside the wrapped call, before `AntController` added any Plate born at that boundary to `MaterialStratigraphy`. Thus `X ∩ prior material` excludes a Plate born at the same boundary. Actual production birth and stratigraphy updates then completed unchanged.
