Base/Born causal decomposition listening

This page provides controlled renders for listening and amplitude inspection. Listening-only files receive per-clip RMS normalization to one shared target (0.020000), so their playback loudness is not an amplitude comparison. The linked 32-bit float measurement files use fixed gain 1 and preserve cross-clip amplitude differences. No subjective or perceptual state is asserted.

Frozen setup: 72000 source frames at 48 kHz; normally one p50 strike at frame 480, strength 0.035, with a 3 ms Born pulse. Condition labels identify the alternate pulse settings, including instant and 1 ms cases. The mapped Base reference uses its recorded p50-mapped schedule. Middle uses P24. Small uses P1 and large uses P26. The 48 kHz rows are rate-aware diagnostic renders; the Born baseline is 6 kHz physics interpolated to 48 kHz. Raw source PCM and full schedules remain in the ignored render index.

Manifest: listening-manifest.json. One audio player per listening clip; measurement links appear only for the seven selected P24 cases.
