# Peak–saddle domain-set audit

This evidence package interprets the complete 8-neighbor B finite-domain ensemble at the same ten frozen P1/P2 states used by the parent reproducibility audit.

**Decision: `DOMAIN AVAILABILITY EXISTS BUT IS TOO UNDERDETERMINED`.** Multi-anchor spatial correspondence and a larger persistent tail are present, but the domain set remains numerous, mostly 1–2 cells, nested in places, and without an intrinsic way to identify materialization candidates. No ranking, proposer or material law was adopted.
