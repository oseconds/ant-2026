## Pass 2 — shortest-route multiplicity shadow (registered before execution)

**Question:** How much of H-to-I omission is caused by committing to one tie-broken shortest-path parent, rather than the boundary-terminal family itself?

**Input:** only the frozen Pass 1 analysis arrays, roots and observed history. No new natural run. Keep chemical/support gates, skeleton, H eligibility, deterministic root, terminal set, minimum path length, width construction and material mapping fixed.

**One principal manipulation:** treatment of equal-cost shortest routes. Three fixed modes, no sweep:

1. Production smaller-row-index predecessor (reference).
2. Larger-row-index predecessor, changing only the deterministic equal-distance tie decision (sensitivity control, not a proposed material law).
3. Union of every shortest predecessor route to the same qualifying boundary terminals, using the production `1e-12` cost tolerance (candidate extraction diagnostic). This includes no extra terminal and excludes longer routes/dead ends.

**Validity:** reference candidate equals recorded production geometry/metrics at all 120 analyses. Source, terminal distances, winner and geodesic length stay identical. The all-shortest union contains the production network; validate every predecessor cost and strict distance descent. Controlled fork/merge/spur fixtures show equal alternatives retained, longer routes and spurs excluded. No RNG. Every mode runs twice on immutable inputs. Never modify production source on disk.

**Readouts:** O recovery, source-grid/ribbon difference, current 32-grid compiled geometry, connectivity/pickup validity, original real-foot opportunities and actual birth-time footprint consequences. Keep the production principal path/pickups fixed for the all-shortest mode; reverse-tie pickup changes are a reported consequence, not timbral evidence. Geometry evaluated at locked actual birth timestamps is not a claim of valid counterfactual birth timing.

**Cost boundary:** exactly 120 saved frames, two deterministic evaluations of three modes; no natural replay. A 60 s wall guard aborts frozen evaluation rather than increasing the horizon or adding modes. Foot readouts are geometric opportunities at original positions, not bridge posts or measured sound.

**Decision:** if tie handling adds only raster-local support or leaves dominant stable omitted structures absent, reject it as an answer to the full omitted-history question. If it changes physical support substantially, inspect event-timing/immutable-layer consequences next before recommending implementation. Neither larger masks nor more cycles is success. No tuning after results, no temporal-revisit gate or extra endpoint family.

## Pass 2 result and continuation decision

The reference matched all 120 candidates. At first birth, reversing the parent tie changes 52 network cells (symmetric difference); all shortest alternatives recover only 22 of the original 506 omitted cells. Ribbon support grows from 356 to 372 cells, and the compiler from 70 to 72 nodes, both connected with valid pickups. At the second locked actual birth the corresponding counts are 181 to 225 network cells, 544 to 581 ribbon cells and 104 to 110 solver nodes. These are geometric compatibility/opportunity results, not counterfactual birth schedules, bridge posts or PCM.

Equal-cost route loss exists but cannot explain the dominant omitted history. Do not promote all-shortest as the new formation direction. The next unresolved distinction is terminal-free appendages versus longer reconnecting paths that a shortest-route family excludes.

## Pass 3 — terminal-path provenance (registered before execution)

**Question:** Are omissions terminal-free pendant structures, or supported alternatives that connect already qualifying regions through longer paths? This is an observational graph classification, not a new selector.

**Frozen input:** the same 120 exact H components, recorded selected root and qualifying observation-boundary terminals. No new world, endpoint, threshold, history field or materialization. Use the winning component, explicitly separating other eligible components if any.

**One distinction:** membership in the union of all simple root-to-existing-terminal paths, computed through biconnected blocks and their marked block-cut subtree. A terminal-free lobe joined through one articulation is pendant even if it contains a cycle. A longer alternate reconnection can be in the hull even when absent from every shortest path. Report sensitivity to the same diagnostic diagonal guard; never interpret small raster cycles as physical loops.

**Readouts:** partition H into production I, equal-shortest alternatives, longer-path hull alternatives and pendant remainder. At first birth, report each group's actual field/contact distributions, pre-birth sampled E/H tenure, later I membership and actual frozen coverage. Track adjacent-frame overlap rather than inventing permanent branch identity. Record coherent pendant groups and hull footprints for review. This does not establish which class deserves material.

**Validity:** partition conservation, I and all-shortest subsets of the hull, unchanged inputs, deterministic rerun and no RNG. Tiny graph fixtures compare the hull to exhaustive simple paths, including a longer reconnection and a single-articulation cyclic lobe. Cost: 120 frozen frames, two graph conventions, two deterministic evaluations; 60 s wall guard. No natural replay.

**Pre-result clarification:** the four-way partition and subset assertion use the production 8-neighbor graph. Removing diagonal edges for the sensitivity graph changes the admissible paths; report any production-I/all-shortest cells outside that diagnostic hull instead of forcing a false subset assertion. Fixed first-birth cohort E/H/I coverage over successive frames describes sampled availability in that footprint, not immutable biological branch identity.

**Decision:** if both graph conventions show omissions predominantly outside terminal paths and comparatively weak/brief history, reconsider the useful-pruning null. If supported history spans both classes, do not invent a global score or freeze the whole hull. Identify whether another technical uncertainty blocks a coherent event definition; otherwise prepare the smallest history-versus-selection review and stop at artist judgement (Gate 4). A hull is an explanatory upper bound, not an endorsed material mask.

## Pass 3 result and continuation decision

At first birth the production graph partitions into I=122, equal-shortest alternatives=22, longer terminal-path alternatives=366, pendant remainder=118. The terminal hull is 510 cells; the guarded diagnostic hull is 488 (22-cell difference). This is not merely the earlier diagonal microcycle count. The 366-cell group's pre-birth E tenure median is 26 s, versus 23 s for I; exact pre-birth foot samples have median 3 in both. The pendant group's medians are 11 s and 1 foot sample. Current pruning therefore mixes exclusion of relatively brief appendages with exclusion of sustained alternative support. None of these groups is an independent natural entity or an endorsed Plate.

The remaining implementation uncertainty is event scope: the existing 20 s candidate timer is not a per-cell material maturation rule. Before asking which richer support should become material, audit what the existing discrete event actually guarantees. This directly tests whether changing geometry alone would silently change the meaning of temporal qualification.
