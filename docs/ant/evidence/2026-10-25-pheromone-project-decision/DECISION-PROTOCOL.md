## Candidate under review: existing G only

- Endpoint grid 316 × 316; existing production Gaussian radius 0.0045, sigma 0.00225, nonnegative Float32 nodal storage, bilinear reads, cap 8, 15-second decay.
- Scale each authored dose by `S = (315/95)^2 = 3969/361` before the existing writer. No sensor/consumer thresholds, movement, recruitment, material rules, renderer mapping or audio changes.
- Nodal values and scalar samples share one **authored point-signal unit**, not calibrated physical concentration. For an uncapped interior write, the reference integrated signal is `A / 95^2`. A 316-grid coefficient sum of `S*A` reconstructs that same integral. Source/profile discretization and nonlinear feedback can still change point samples and behavior.
- This is a conditional engineering convention, not universal conservation: edge/corner basis areas, clipped/renormalized kernels, rejected outside deposits, Float32 rounding and cap loss remain explicit exceptions.
- `totalMass` remains a legacy native node sum, not a comparable physical quantity across resolutions. Existing G's returned accepted request is in **scaled coefficient-request units**, whereas controller input is authored dose. Current controller ignores those return values. Production-candidate review must specify/label those units and the node-sum diagnostic; no claim treats a requested return value as actual stored increment.

This contract is technically coherent if every important consumer reads the same point signal. Differing activation/material/movement outcomes are then endogenous consequences of a changed represented signal, not automatically a unit contradiction. A consumer that interprets the same values in incompatible units is a contract blocker.

## Decision gates

1. **Representation evidence:** preserve the published fixed-cue decisions and their scopes. G's earlier fixed-cue pass is sufficient for this review; do not rerun the whole cue chain.
2. **Shared semantics:** audit all production readers, snapshots, diagnostics, cap/boundary and public dose/return interpretation. If no coherent common quantity can serve them without compensating threshold changes, recommend contract redesign.
3. **Behavior evidence:** use valid cumulative measures and corrected recent occupancy only. Population/finite/speed/collision/cap violations or measured loss of continued movement would be blockers. Do not equate upper Hill histogram bins with complete loss of discrimination. Do not add an artistic morphology threshold or infer individual trapping from gridded concentration.
4. **Operational screen:** compare C/G in actual foreground Chrome, same viewport and one seed after 600 simulated seconds. Report cost and overhead, RAF progression, simulation/wall, discarded time from the production 100 ms frame-gap clamp, memory observations and errors. A sustained real-time shortfall or accumulating discarded simulation time blocks an unqualified runtime-feasible recommendation. Isolated costs are not whole-app guarantees; a short run cannot establish memory-leak absence or hours-long stability.
5. **Adoption boundary:** an advance means review of this one candidate, not a merge, exhibition acceptance or adoption. It does not require reproducing the 96-grid morphology. Any remaining API/diagnostic integration work must be named. If one specific unmeasured property actually prevents this decision, name it; otherwise stop research and return the decision to the project roadmap.
