## Shared quantity and representation contract

**IMPLEMENTATION FACT:** production treats node values as spatial samples in every reader, but calls their sum `totalMass`. At N=96, `h=1/95 > 2R`; the compact brush can reach at most one node and otherwise falls back to the nearest. The implemented field is therefore a coarse spatial signal, not a calibrated chemistry solver.

**ENGINEERING CONTRACT FOR G:**

1. `values[i]` and bilinear `sample(x,y)` express the same nonnegative **authored point-signal unit**. The normalized world square supplies positions/area; the unit has no biological or physical chemistry calibration.
2. An authored source request `A` corresponds to the legacy reference integrated signal `Q_ref=A*h96²`. With N=316, the existing Gaussian writer receives coefficient request `A*S`, where `S=h96²/h316²=3969/361`. For an uncapped write whose active nodes are interior, integrating the reconstructed field gives `Q_ref` within Float32 error. This preserves an integrated convention, not every point sample or the old footprint.
3. The physical **nodal write** radius remains 0.0045, sigma 0.00225. Bilinear reconstruction can extend beyond it, as it already does in C. Exact compact readout radius and exact first moment of every Gaussian write are not promised.
4. Half-life remains 15 s for the common point signal; cap 8 remains a point-signal cap. At boundaries use the existing truncated/renormalized writer, edge/corner bilinear basis and outside rejection. At cap use the existing per-node clamp without redistribution. Global conservation at these boundaries is not claimed.
5. Requested source dose, internally scaled coefficient request/return, actual stored increment, reconstructed integral, and native node sum are separate quantities. G's operational API currently returns a scaled request, not actual stored dose after cap. The controller ignores those returns. That legacy API must be made explicit in an adoption diff; no consumer should infer accepted physical mass from it.

For a finite grid, the exact bilinear integral is `h_x*h_y*Σ β_i β_j values[i,j]`, with endpoint weights 1/2 and interior weights 1. `Σvalues` is only native node sum. It is not resolution-comparable. Do not preserve it as the conservation target merely because tests call it mass.

This resolves the earlier contract investigation's **modeling ambiguity**, not its theorem. G deliberately uses approximate Gaussian moments, a nodal radius and conditional reference integral. Requiring exact continuous moments, unchanged point amplitudes, strict reconstructed radius and unconditional boundary/cap conservation would be a different contract and still require redesign. No such universal requirement has been established for ANT.

## What ANT should do next

Submit **G only** to a separate adoption review. Preserve the common point-signal contract, the conditional reference integral, unchanged sensor/material thresholds, physical Gaussian and startup choice boundary. The smallest production adoption diff would be field construction plus writer unit conversion, explicit public dose/return accounting and a truthful native-sum/integral diagnostic label. This pass supplies the research field and evidence; it does not change the production factory or defaults.

At that review, choose whether the documented boundary/cap exceptions and authored signal are appropriate for ANT. If unconditional physical-mass conservation is desired instead, that is a new contract requirement and redesign is necessary; do not smuggle it into this candidate. API/diagnostic integration and its regressions are concrete remaining work, not a reason for more secretion ablations.

Stop QAKR/CIC-profile tuning, resolution/gain sweeps, exact-moment escalation and concentration-cause hunting. Return to the broader project roadmap after the adoption decision: movement-law qualification, natural collective-route evidence and exhibition persistence remain separate tasks. G is not a solution to every spatial-dynamics goal.
