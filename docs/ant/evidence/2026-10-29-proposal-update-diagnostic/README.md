# Proposal update diagnostic — 2026-10-29

**Decision: `INCUMBENCY DESERVES FURTHER DESIGN`.** In both frozen events, most cells removed from the previous finite proposal remained in the next saved `E`; some removed cells belonged to the previous principal path, and their saved qualification ages were often several seconds. This makes proposal update a distinct design question worth examining. It does not show that those cells should have remained selected: `E` retains history, and the measurement cannot tell meaningful incumbency from obsolete but still-qualified history.

This is an UPDATE-only diagnostic over the frozen P1/P2 anchors. It changes no production law, creates no body prototype, and does not investigate EMERGENCE.
