## Registered orientation measures

Only realized post-collision segments enter these measures. The segment midpoint assigns a segment to spatial support; its normalized displacement `(ux, uy)` supplies orientation.

- Segments are timestamped at their midpoint `m = (tick - 0.5)/60`. For endpoint `e = 1, 2, ... 300 s`, each exact rolling window is half-open `[e-W, e)`, where `W` is 5 or 20 s; thus adjacent windows separated by `W` do not share segments.
- For each time window and spatial cell, retain nonzero-segment count `N`, mean polar vector `P = mean(ux + i uy)`, polar strength `|P|`, mean nematic tensor `Q = mean((ux + i uy)^2)`, and nematic strength `|Q|`. Global order summaries use the same definitions over eligible segments. `P` distinguishes aligned travel from opposing traffic; `Q` is unchanged when travel reverses by π. `N` counts only nonzero segments. A local complex order vector is numerically zero/unavailable when its magnitude is `≤ 1e-12`; this fixed arithmetic tolerance is not a natural organization threshold. Report magnitudes and support counts continuously.
- Locked grids: `24×24` and `48×48` over `[0,1]²`. Locked rolling windows: `5 s` and `20 s`, evaluated at integer-second endpoints; overlapping windows are explicitly treated as dependent.
- For local direction, persistence, and winding support, report validity at minimum cell counts `N ≥ 1, 3, 5`. These are observer-support sensitivities only. They do not define a natural defect, ant role, or organization class.
- Boundary-following is described by the continuous relationship between segment midpoint distance to the nearest domain edge and absolute alignment with that edge's tangent. Report the Pearson correlation plus ten fixed equal-width distance bins over `[0,0.5]` (`0.05` width; the last bin includes `0.5`) with segment count and mean absolute tangent alignment. For an exact distance tie at a corner, choose in this fixed order: left, right, top, bottom; do not replace an equal nearest distance. Interior winding is computed only on elementary closed grid loops that do not touch the domain edge, have all four vertices valid at the selected support count, and have `|P| > 1e-12` or `|Q| > 1e-12` respectively at every vertex. Traverse vertices top-left, top-right, bottom-right, bottom-left, with positive x right and positive y down; wrapping uses `[-π,π)` at the branch cut. Report every valid loop count and signed winding value. For complex polar winding, `wP = Σ wrap₂π(Δarg P)/(2π)`. For nematic director charge, `sQ = Σ wrap₂π(Δarg Q)/(4π)`, exactly half the complex winding of `Q`. Do not fill unsupported cells, wrap the world boundary, select favorable loops, or call a winding value a natural defect threshold.
- Persistence is support-intersection-weighted angular autocorrelation between fields from non-overlapping windows. For `W=5 s`, lags are `5, 10, 60 s`; for `W=20 s`, lags are `20, 40, 60 s`. For field `Z=P` or `Q`, endpoints `e` and `e+lag`, and cells valid at both ends, compute `cᵢ = Re(Zᵢ(e)·conj(Zᵢ(e+lag)))/(|Zᵢ(e)||Zᵢ(e+lag)|)` and `ρ = Σ min(Nᵢ(e),Nᵢ(e+lag))·cᵢ / Σ min(Nᵢ(e),Nᵢ(e+lag))`. Exclude zero-magnitude vectors using `1e-12`; report matched-cell count and total intersection weight for every support setting. Do not convert a correlation into a binary persistent-role label.
- Report all four grid/window combinations, all support levels, and all prespecified temporal lags. No parameter search, smoothing change, or favorable-time selection is allowed.

## Pre-analysis amendment: boundaries between orientation domains

Added on 2026-11-02 before opening any natural trajectory or result output. The registered capture is in progress; this offline diagnostic uses the already locked grids, windows, endpoints, support counts, and arithmetic tolerance. It does not replace the separate world-edge tangent analysis above.

- At every endpoint, grid, and window, examine each undirected horizontal and vertical adjacent-cell pair exactly once. Both cells must be interior cells (row and column indices `1 ... grid-2`), meet the selected `N ≥ 1, 3, or 5` support setting, and have `|P| > 1e-12` or `|Q| > 1e-12` as applicable. Unsupported and edge-ring cells are excluded; no interpolation or smoothing is used.
- For `Z=P` or `Q`, pair mismatch is `δ = arccos(clip(Re(Z₁·conj(Z₂))/(|Z₁||Z₂|), -1, 1))`. The polar mismatch range is `[0, π]`. Nematic director mismatch is `δQ/2`, range `[0, π/2]`, so reversing the underlying travel direction does not create a nematic mismatch.
- Save the valid pair count, mean, NumPy linear quantiles at probabilities `0, 0.25, 0.5, 0.75, 0.9, 0.95, 1`, and 12 equal-width fixed histogram bins spanning the full applicable mismatch range; the final bin includes its upper endpoint. Also save Pearson correlation of pair mismatch against the geometric mean `sqrt(N₁N₂)` when defined. This pair-level correlation is descriptive and repeated neighboring observations are not independent.
- These adjacent-cell mismatch summaries describe where sampled orientation changes occur between nearby supported cells. They do not segment domains, identify a defect, define a natural boundary threshold, or establish a biological or material entity. No post-view metric or threshold will be added.
- As an ancillary numerical-stability description requested before opening the natural trajectory, report realized nonzero segment displacement quantiles at probabilities `0, 0.01, 0.05, 0.25, 0.5, 0.75, 0.95, 0.99, 1`. Units are normalized-domain distance per `1/60`-second segment. This distribution does not exclude or down-weight any segment.

## Plate relation and reference

Compare the observed prior-material overlap rate with the same-time horizontal reflection of that union (`x → 1-x`). This fixed reference preserves row-wise material area, distances to all four domain boundaries, and the fixed entrance axis `x=0.5`; it deliberately changes the local traffic/Plate alignment. Report segment count, traveled length and both distance-weighted overlap rates in fixed 60 s bins `[0,60), ... [240,300)` and overall. The fixed-scale orientation atlas uses all five endpoints `60, 120, 180, 240, 300 s` for every grid/window combination and displays local fields only at `N ≥ 3` as a visualization support setting.

This single deterministic reflection is a spatial reference, **not** a statistical randomization test or a causal null.
