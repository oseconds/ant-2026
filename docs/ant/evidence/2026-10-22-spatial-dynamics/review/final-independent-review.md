# Independent final review

## Disposition

The current non-adoption conclusion is supported: the intervention changes individual realized route turning in the three tested 600-second seeds, but the evidence does not establish repeated shared curved corridors, spontaneous colony-scale regime renewal, or an integrated exhibition candidate. The two-hour material comparison is a single-seed counterexample to assuming that smoother local movement preserves open composition. None of these observations justifies changing production behavior. The source baseline and canonical status are explicitly identified as unchanged in `REPORT.md:7,9,110-111`.

I found no blocker to those bounded conclusions. One speed statement should be relabeled because it is based on net displacement, and one optional analysis column is currently always null. Neither affects the central route-turn result or the separately computed recruitment field-axis comparison. The reported human assessment is correctly treated as one person's judgment that the two diagnostic images make route and temporal differences readable, not as biological, material-renewal, or runtime evidence (`HUMAN-REVIEW.md:3-7`).

The review covered the current study sources, reports, tests and retained captures, excluding `docs/ant/archive/**`. I did not rerun simulations, tests, or the build. The evidence package's 16 raw/gzip pairs round-trip to the recorded raw hashes. Existing validation records show exact selected-stream prefix parity, 364/364 tests, and a successful build; these validate the runner and package, not the scientific interpretation.

## Findings

### [P2] “Mean speed” is a one-second net-displacement rate

`ant-spatial-run.js:90-105` keeps the first and last position for each ant in a one-second interval and emits their difference as `dx/dy`. `ant-recruitment-descriptors.js:28-35,58` divides that net displacement by the interval and calls the result `meanSpeed`. A curved or alternating path can have a lower net-displacement rate despite unchanged path length per second, so the comparison is confounded by the very turn-geometry change under study. The statement that mean speed “changed only slightly” in `movement/results.md:56` and `REPORT.md:49` should be labeled **mean one-second net-displacement rate**; it should not be used as evidence that locomotor speed was unchanged. The separate per-tick path-turn measures do use successive actual positions and distinguish those from body-heading change (`ant-route-curvature-metrics.js:48-93`), so this naming issue does not invalidate the main movement result.

### [P2] Optional pheromone-orientation coherence output is always null

`ant-recruitment-descriptors.js:116-119` returns `pheromone.orientation` as an object with `angle` and `concentration`. `ant-spatial-analysis.js:43` passes that object to `Number.isFinite` and therefore writes `null` for `pheromoneOrientationCoherence` for every frame; the retained natural-analysis summaries show that null column. This leaves that optional spatial-analysis measure unavailable. It does not invalidate the separate recruitment analysis, which reads `orientation.concentration` directly, or any headline claim in the report. If this column is used later, first decide whether it means directional concentration or an unoriented axis statistic, then compute and label that quantity explicitly.

### [P3] Bound the reproduction note to the streams actually compared

`validation/long-prefix-parity.json:3,12-38` compares exact JSON for four selected streams: public checkpoints, one-second frames, ten-Hz active-ant trajectories, and accepted-spawn records through 600 seconds. It expressly excludes whole-run summaries and final state (`:39-43`). `REPORT.md:118` names the compared streams accurately. `REPRODUCE.md:65` then says the check “includes actual captured state and event history,” which can sound broader than this comparison. Tighten that phrase to name the four streams; do not imply equality of every tick, contact, RNG call, or full final state.

### [P3] Clarify the lag unit in the movement table

The route-curvature helper computes `pathTurnLag1Correlation` over successive per-tick travel-turn samples (`ant-route-curvature-metrics.js:62-70,107`). The table label “1 s lag-1 path-turn correlation” in `movement/results.md:46` can be read as a one-second lag, although the one-second designation describes the aggregation window and lag-1 is one sample (one 1/60-second tick). A label such as “lag-1 correlation of per-tick path turns, summarized within 1 s windows” avoids ambiguity. This is a naming issue; the reported paired sign and magnitude changes remain descriptively supported.

## Causal and architectural audit

- **The `dt` factor is a large gain reduction, not a demonstrated unit repair.** At fixed `dt=1/60`, the maximum raw term falls from about `1.43 rad` to `0.0238 rad` (`REPORT.md:25`; `movement/results.md:13`). Only one fixed step is tested, and the remaining controller is not shown to be timestep-invariant. Damping-off often resembles the candidate, while deposited S and mirrored-arc tracking still fail (`REPORT.md:47,90`). The evidence supports “reducing the delayed previous-omega contribution changes turning,” not “the controller's units were corrected” or “this is the uniquely right damping law.” The report states that boundary correctly.

- **Actual path turning and body turning are separated in the instrumentation.** The run captures actual post-collision segment endpoints (`ant-spatial-run.js:61-91`); route metrics derive travel headings from consecutive positions and calculate body-heading changes separately (`ant-route-curvature-metrics.js:48-93,109-112`). Thus the three-seed result supports an individual realized-path change, alongside body-cap relief. It does not measure repeated use of shared curved corridors or collective route geometry, and the report does not promote it to that claim (`REPORT.md:45-49,96,104`).

- **Same seed is an initial condition, not a post-divergence common-random-number control.** The changed heading can alter exits, spawn timing, contacts, and later RNG consumption. The report distinguishes the intervention's total natural consequences from a time-paired effect (`REPORT.md:17`); the recruitment record also documents first heading/event divergence and differing RNG totals (`recruitment/natural/analysis/ANALYSIS.md:33,64-70`). Controlled short movement probes hold cues fixed and are useful local contrasts, but they do not make later free-running trajectories or material histories paired.

- **Outgoing flow uses completed movement from the current tick.** The research wrapper clears segments at tick start, captures gait segments, and makes the end-of-tick accepted-spawn heading from those same-tick segments (`ant-spatial-core.js:42-64,69`). The receipt and recruitment protocol state that timing explicitly (`PLAN.md:15`; `recruitment/natural/analysis/ANALYSIS.md:7`). It is not a one-tick-lagged survey. The newborn is not counted as having moved before its own spawn.

- **The field gate failed; CIC was correctly not tested.** The predeclared criterion requires winner changes in at least two of four geometry families (`field/PROTOCOL.md:26-28`); the result is 2/24 pairs, both in the tight-circle family (`REPORT.md:53`). The report correctly calls this a failed gate, says no CIC alternative ran, and retains local-signal differences as evidence of controlled phase sensitivity (`REPORT.md:53-55`). This does not establish field irrelevance. The next-step wording now says any representation comparison needs a separately authorized, preregistered question and is not a continuation of the failed gate (`REPORT.md:112`); I find no remaining CIC-gate reversal in that recommendation.

- **Upstream route diversity does not identify selector causality.** The candidate and born-Plate curvature summaries are differently selected cohorts, not paired transfer observations (`REPORT.md:67-69`). The current formation chain also includes gaster deposition and raster fallback, foot-contact support, chemical memory/thresholds, source-annulus and boundary constraints, path selection, persistence/repeat requirements, and birth spacing (`AUDIT.md:25-31`). Those mechanisms can change whether a changed ant route becomes a candidate and whether a candidate becomes immutable material. Since the pass does not isolate those links in matched natural states, it cannot rank a dominant selector cause; the report properly says so (`REPORT.md:69,98,103`).

- **The 99.20% versus 77.34% comparison is correctly limited.** It is one production/dtFeedback seed pair at 7,200 model seconds and reports occupied cells in the 96×96 material mask, not an aesthetic score, biological regime, or cross-seed law (`REPORT.md:71-82`; `analysis/long-run-final/README.md:43`). Because the union is append-only, near-full coverage is saturation, not renewal of empty space. The 600-second check is exact only for the four listed streams and should stay described that way (`validation/long-prefix-parity.json:3,12-43`).

- **No integrated mode or canonical adoption claim is appropriate.** The package explicitly leaves production source, renderer, audio, cap and canonical status unchanged and calls the movement and flow conditions research-only (`REPORT.md:7,110-111`). The visual assessment does not override failed deposited-route cases or near-saturation evidence. Test/build success is implementation validation only; it cannot establish spontaneous collective organization, exhibit stability, or artistic preference.

## Claim blockers versus finishing items — initial review state

There was no claim blocker to retaining the negative/inconclusive result and non-adoption boundary. At the initial review checkpoint, the speed wording, null pheromone-orientation output, and two wording clarifications were remaining analysis/documentation defects. ## Follow-up verification — 2026-10-23

I rechecked only the requested fixes against the current report, tool, test, and regenerated analysis files. I did not rerun a world simulation, the analysis writer, the test suite, or the build; I made no production-source change.

- The `meanSpeed` wording is corrected in `movement/results.md:56`, `REPORT.md:49`, and the natural recruitment analysis. It is now explicitly called a one-second net-displacement rate and disclaimed as evidence of unchanged path speed. This resolves the reporting defect; the underlying descriptor remains a net-vector measure.
- The movement table and report now call the statistic adjacent-tick path-turn correlation within one-second windows, and state that lag one is one 1/60-second sample (`movement/results.md:46,56`; `REPORT.md:45`). `REPRODUCE.md:65` now bounds exact prefix parity to the four compared streams and explicitly disclaims every-tick state, contact, and RNG equality. These wording issues are resolved.
- `ant-spatial-analysis.js:44` now reads `pheromone.orientation.angle` and computes `cos(2 * angle)`, returning null if direction is absent. The regression test covers `angle = π/2` yielding `−1` and missing direction yielding null (`tests/ant-spatial-analysis.test.js:27-37`). The validated analysis outputs contain finite values where an angle exists, with nulls retained where it does not. `short-analysis-parity.json` records the same source hash across retained-input cases and confirms that prior temporal/window values match except for the repaired direction-derived column. The old output version remains preserved.

The corrected pheromone column is an **unoriented coordinate diagnostic** derived from the direction angle. It is not the directional-resultant concentration returned alongside the angle, and it must not be read as field strength or confidence. At this recheck, `analysis/README.md` documents doubled-angle `cos(2θ)` for the ant covariance axis but does not yet define the separate pheromone orientation column; the column name `pheromoneOrientationCoherence` could imply concentration. Add a short definition to the analysis guide before treating that column as a human-facing result. This is a documentation/labeling finish, not a blocker to the report's present conclusions, which do not rely on this column.
