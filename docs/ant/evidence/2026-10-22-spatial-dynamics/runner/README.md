# Spatial dynamics runner

This folder documents the reusable diagnostic runner. No production behavior or research condition is selected here.

`scripts/ant-spatial-run.js` exports `runSpatialCase({ Controller, receipt, seed, seconds, output, label, ...controllerOptions })`. It advances fixed 1/60 s model ticks and returns model and wall time separately, 1 Hz spatial/material summaries, exact public-state checkpoints at 30/120/300/600/1200/1800/3600/7200 s, 10 Hz trajectories, full-tick flow availability summaries, accepted-spawn records and flow/spread summaries, final lifecycle/material counts, source hashes, and 1/2/5 s route-curvature summaries. It consumes `spatialObserver` hooks from the injected controller. The CLI accepts one `--seed`, one `--seconds`, and one `--output`; it does not launch a matrix. Output writes and per-run source copies refuse replacement.

Movement samples use the controller's completed-tick observer segments. The core records actual postcollision segments, including the outward segment on retirement; the runner uses actual displacement to derive speed and 1 Hz movement descriptors. The runner verifies current source hashes against frozen per-run copies before writing results. Curvature keeps one compact sample record per ant per tick until its summary is computed; very long durations with many replacements may use substantial memory.

Spatial frame descriptors reuse `describeSnapshot` from the recruitment survey, with one-second accumulated actual displacement and the current copied pheromone field. Material summaries are derived from copied public stratigraphy snapshots: union area/change/retention, exposed and buried cells, depth/layers, births since prior frame, top identity changes by cell, and nodule count. Fixed checkpoints deep-copy public snapshots, including chemical, surface, material, and birth state arrays/histories.

Validation: plain production and north-observer controllers matched every public snapshot and RNG state for 600 ticks; the observer emitted unique per-ant segments and one accepted-spawn observation per accepted ant. A direct hook check verified every post-init spawn flow deep-equaled the completed same-tick flow, its time equaled `tick/60`, and north heading matched the original formula exactly. The three natural baseline runs are documented in [`../baseline/README.md`](../baseline/README.md). Initial sandboxed `node --test` hit `spawn EPERM`; the parent later completed the normal full suite with permitted process execution, **364/364 passed**. The stale runner test's frame-shape assertion was corrected to the nested public descriptor schema. No runner world logic changed for that correction.
