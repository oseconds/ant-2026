## Initial prototypes (not a Cartesian grid)

Source width bounds are reused unchanged: `r0=.012`, `r1=.030` world units. These are existing TrailPlate half-width bounds, not fitted to outcomes. A linear interpolation inside these bounds is an authored exploratory hypothesis. Chemical memory and compaction already lie in0–1; no per-event normalization, percentile, ranking or new threshold is permitted.

- **P / actual reference:** current frozen production mask and actual material. No new family.
- **K / constant scaffold control:** Euclidean sleeve `d(x,I)<=r0` around the actual selected I cells. This isolates the finite scaffold from history shaping. It is a diagnostic control, not an improvement.
- **S / chemical sleeve:** `d(x,I)<=r0+(r1-r0)*B(x)`, using actual commit chemical memory. History modifies the transverse contour, not E membership. Compare with K.
- **R / redundant-connection sleeve:** same chemical contour rule around the prior terminal-path hull (selected, equal-shortest and longer-supported alternatives; no pendant remainder). Compare with S to expose structural selection's responsibility. This is the same sleeve construction with a different connection concept, not another texture style.
- **M / mechanical contour:** same terminal scaffold, `d(x,T)<=r0+(r1-r0)*C(x)` using raw SurfaceField. Chemical and mechanical roles need not be symmetric. Compare with R; do not infer a levee or literal foot-scratch direction.
- **L / reconnection lamina:** terminal chemical sleeve plus bounded complementary pockets enclosed by the terminal raster scaffold. Interior filling is the proposed body concept, not post-hoc cleanup. Keep every pocket; compare4/8-neighbor complement to expose raster artifacts. This hypothesizes spanning material between connections and may be rejected if that meaning or the representation fails.
- **Q / character-only comparator:** same K geometry, with whole-Plate coefficients from mean B and mean production support D over that body using the existing material mapping. Demonstrates an alternative responsibility: history can characterize rather than widen. No local stiffness/thickness map or color-only success claim.

All geometry candidates initially keep actual whole-Plate material coefficients. Bounded technical fixtures also hold actual `meanHalfWidth` (and thus current whole-Plate thickness convention) fixed to separate mask changes from vertical-depth changes. Report prototype radius statistics separately. Compiler fixtures clear obsolete `edges`/centerline/path metadata instead of secretly filling new masks from old routing edges. Actual full-descriptor compilation can be reported as a reference separately.
