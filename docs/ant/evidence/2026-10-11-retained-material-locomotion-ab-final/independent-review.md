# Independent review

**Result: PASS, no blocking findings.** SUPPORTED is warranted for this exact bounded candidate as a candidate for later production-world-law consideration. It does not establish a broad material-mediated law or authorize production adoption.

The fresh reviewer read the controller, candidate test, A/B harness, paired results, time windows, manifest and daily entry. Review was read-only. The reviewer did not rerun simulations, tests or build.

## Findings

- **Causal timing:** the public stratigraphy snapshot is captured at tick entry. The controller uses the ant's tick-entry position after existing intention, steering, turning, crowding, following-speed and hesitation calculations. Same-tick births are visible at the next boundary. No future-state leakage was found.
- **Treatment isolation and Control parity:** the opt-in flag defaults Off. Treatment changes only the current-cell layer-count multiplier. No RNG or second behavioral input is added. The saved Control chains match the prior baseline on 14 declared fields for 36,001 rows per seed; the observer's pre-tick read is checked for mutation. No post-divergence equality is claimed.
- **Movement/contact interpretation:** active ant-time increased in each Treatment, while mean realized speed fell 3.40-4.43%. FOOT_CONTACT points per active ant-minute fell 3.51-4.53%, but contacts per travelled-distance unit stayed near 165 in every run. Contact counts therefore track lower travel and are not independent confirmation of a separate contact effect.
- **Episode interpretation:** an episode stays open while the ant center is on any exposed material; a top-Plate identity change does not close it. The duration statistics are continuous any-exposed-material episodes, not dwell on a single Plate or cell. Horizon-censored episodes are 0.8-1.1% by run.
- **Scope:** Plate-birth, coverage and layer outcomes move in mixed directions, and nodules hit the existing cap in all runs. Those limits do not negate the measured locomotion/activity effect but restrict claims about material formation.

No code or evidence files were changed by the reviewer. The evidence README incorporates the contact-rate and episode-definition qualifications.
