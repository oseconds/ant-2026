# Joint scope–BODY grammar: one primitive is supported; mode routing remains open

## 1. Decision and evidence boundary

**[Synthesis]** Frozen ANT inputs admit finite chain, branching-motif and enclosed-support mask constructions without converting all qualified history into material. This is offline geometry, not new compiler/solver qualification. The packet does **not** justify an automatic plural materialization grammar. The strongest current null survives: **one ordinary structural-sleeve primitive, used on an explicitly selected finite scope, with existing whole-Plate character and post-commit geology**. A local unit can change the object substantially without a new BODY mode. Selecting which unit belongs to an event remains a real responsibility, not a solved consequence of graph partitioning.

**[Authored material semantics]** A second, coherent *possible* meaning survives: an already bounded support boundary may cohere across its enclosed interior. This is different from convexifying every branched object. We demonstrate a small local construction, but the observed boundary does not share the existing event's full maturation history. No natural mode router or new event law is inferred.

**Plurality assessment:** one primitive is the provisional minimum; multiple **scope types** are available; multiple **material modes** remain unestablished. Composition of identical sleeves is exactly the same body as direct union. Multiple Plate IDs per environmental episode would change cardinality and is parked. This is a research direction, not production adoption, a final universal scope law, or an artistic winner.

Labels used throughout: **[Implementation]**, **[Prior result]**, **[New measurement]**, **[Synthesis]**, **[Authored material semantics]**, **[Unresolved artist choice]**. A raster fact is not a biological construction event, physical load path or audience judgment.

**[New measurement]** Partition every edge into maximal chains, retain isolated nodes, apply the **same** sleeve primitive to each, then union within one object. ## 5. Coherent grammar candidates, without a product grid

### G0. One committed representative, one structural body — minimum null

Scope is one event's selected finite representative at COMMIT, temporarily current I. K-like ordinary union turns it into matter; existing context supplies one tuple. Real omitted history remains outside. One event creates one Plate; it closes at existing COMMIT and later layers remain independent. No new mode router or branch IDs.

Finiteness comes from selected scope and bounded sections, not complete field eligibility. Source/boundary still author current scope, but the BODY primitive does not require those terminal meanings. This is compatible with an open-window successor without claiming to implement one. It carries the fewest new assumptions. Existing K interface checks are prior evidence, not requalified for new local units here.

### G1. Unit-sized materialization, one BODY primitive

A selected finite chain or branching motif defines the object, with the same sleeve on either. Valid other units stay outside this commit. This can change object extent substantially without special BODY. It is a **scope-unit architecture**, not proof that ANT needs several kinds of matter.

One chosen unit could still create one Plate at a commit. But a graph decomposition does not decide which unit the event selects, which maturation it inherits or how a later unit is reissued. Longest/largest example selection is not promoted as that answer. Parent-tree units remain conditioned by the current source-rooted selector and do not supply independent episode identities. Open-world portability is conceptual at the unit/primitive interface; current natural emergence is untested.

**Disposition:** useful research simplification; no complete automatic scope-unit law yet.

### G2. Situation-dependent cohesion: open structure stays sleeve, bounded support may become lamina

An open selected unit uses K. A separately justified closed-support situation could use its bounded interior as well. This is an **event-level mode** only if one situation is selected and matured as that event; one descriptor still results. It need not have different material coefficients or geology. Enclosure supplies a finite spanning domain without arbitrary hull/alpha radius. It introduces the authored premise that supports can cohere across a gap.

Two routing meanings must remain open. A **COMMIT-snapshot grammar** may use the selected unit's current closure under the already mature event; it does not require a fresh20s face timer. A **closure-history grammar** instead claims that an actual support transition organizes the new mode and needs evidence for that transition. Neither may use induced cycle rank or a newly generated body hole as proof of past closure. Our late face availability limits the second claim, not the logical possibility of the first.

The unresolved selector responsibility is which current finite scope represents the event: I, one H-face, another unit, or none. Choosing the largest face was an atlas sampling rule, not its answer. Current I tree selection suppresses selected ancestral loops, while broader H contains raster enclosures. Moving to H-face scope is substantive. Connectivity convention and the added cohesion meaning still need to be declared.

There is also a simpler competing architecture: an **identical enclosure-conditioned construction for every selected unit**, rather than two event modes. Open units receive sections; a selected closed unit additionally spans its declared bounded interior. This could be one universal material operation. The local pair is compatible with that interpretation too; it does not prove a mode router is needed. Its exact behavior on all possible units, especially incidental BODY-created holes, was not implemented or qualified here.

**Disposition:** coherent possible second meaning, unresolved router. No `if closed then lamina` production proposal, unit timer or forced reset.

### G3. Heterogeneous primitives inside one Plate

Chains could remain sleeves while selected junction/closure units use spanning patches; union them and commit once. One Plate with one tuple can represent that binary footprint in principle. A special junction would be authored cohesion, not simulated stress/flow accumulation. Raw degree is not adequate routing evidence; parent-tree degree is more faithful to the selector but still not a physical constitutive event.

All-sleeve composition is the exact null above. Adding Hull to every junction is not justified by the tiny4/1-cell local examples or by the former global Hull contrast. No new local material hierarchy or solver coefficient map is needed merely to show geometry, but such maps would be a larger architecture if demanded.

**Disposition:** park heterogeneous composition; retain homogeneous factoring only as an implementation identity, not an extra mechanism.

### C. Several objects from one environmental episode — separate cardinality architecture

No frozen branch-specific START/maturity/reuse contract creates simultaneous independent Plates. Emitting each chain/motif would multiply IDs, change repeat suppression, pickup responsibility and layer/runtime burden. A source graph partition is not evidence for those objects' separate temporal lives. Later independent commits and same-place layers are already possible.

**Disposition:** not required by this investigation; do not casually promote finite unit count into object count.

## 7. Recommended working grammar and one next closed pass

**[Synthesis]** Retain **one structural BODY primitive** as the default working architecture. Allow a grammar investigation to nominate finite structural **units**, but keep unit selection, eligibility and cardinality explicit. Do not add automatic plural-mode routing yet. Treat the bounded enclosed-fill as a second *material meaning under examination*, not another default. This neither forces one universal scope nor assumes all events need different bodies.

**[Unresolved artist choice, primary]** When a selected finite boundary exists at COMMIT, is its interior still an unsupported void, or can materialization cohere across it? The question is what materialization does, not which panel looks better. If cohesion is not wanted, no second BODY mode is currently needed. If it is wanted, distinguish a current-topology operation from a record of an actual closing episode. That second meaning question determines whether temporal provenance matters. Choosing local versus whole-network object identity remains a scope responsibility; no numerical parameter is handed to the artist.

**Next smallest closed technical pass, only if a closure-history discriminant is intended:** use the existing P2 transition105.016667→106.016667s. Ask: **did the newly available H enclosure arise from a local qualified-support connection, or from thinning/adjacency/selected-component representation?** Freeze the saved E/H/source and exact face coordinates at both anchors. Compare the face boundary's E membership and deterministic skeleton representation; hold thresholds, event clock, source and every material primitive unchanged. No new BODY, coefficients or natural simulation. A COMMIT-snapshot interpretation does not require this pass merely to justify using a late current unit.

Falsifier: if the apparent closing boundary was already part of the same qualified support and only its skeleton/representation changed, or closure cannot be distinguished under justified adjacency conventions, do not use it as evidence of a new support-history transition. This would not falsify an explicitly authored COMMIT-topology operation. If a definite qualified-support transition exists, it supports a *candidate discriminant* only; it does not supply cohesion or inherit20s face-specific maturation. Stop there rather than adding a closure timer or tuning a mode classifier. If cohesive interior or closing-history meaning is not wanted, skip this pass.

This conditional pass is **not executed here**. The present exploration stops with unit availability, exact composition null, a bounded local-spanning countermodel and an explicit routing gap. More silhouettes or another600s run cannot choose the missing material meaning.
