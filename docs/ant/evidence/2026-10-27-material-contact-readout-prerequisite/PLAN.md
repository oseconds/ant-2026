# Material-contact readout prerequisite — registered decision and plan

Registered before measurement on 2026-10-27 (Asia/Seoul).

## Decision memo

**Decision: MEASURE A PREREQUISITE BEFORE RENDERING.**

The current question is whether an independently meaningful use-history readout can be built from the actual exposed-contact stream. It is not yet whether a particular dot style looks like matter.

The proposed World-Locked Medium condition is not an independent manipulation as stated: the existing View 4 already indexes a fixed Bayer matrix by native canvas coordinates, with no trail-local phase. At fixed camera and canvas size this is world-locked. A longer-scale or anisotropic rule would change a different variable, which must be specified before comparison. The artist's response remains a response to the existing particular screen, not a refutation of every spatial medium rule.

Fossilized contacts are a distinct candidate, but add individual-event rendering memory that current aggregate state does not retain. Event eligibility, ownership after burial, Audio-Off independence, and physical/display cell registration must be settled before choosing glyphs or visibility parameters. Comparing fossils with Bayer alone would compare provenance, temporal accumulation and spatial grammar together.

## Falsifiable decision rules

- Any event/post ordering, exposed-route, input-mutation, prior-H1 or twin-parity failure invalidates the measurement; report inconclusive rather than patching the world.
- If eligibility is transport-dependent only at posting, define any future visual source as audio-independent eligible exposed contacts, with ready-port posts serving as a routing oracle. An Audio-On posting archive cannot be the universal visual history.
- If contacts become buried or disagree with displayed support, a future fossil pass must retain Plate ownership and explicitly state visibility/clipping policy. It must not silently turn layer history into always-visible world-coordinate ink.
- Zero/low historical-contact opportunity in this early window weakens that window as a test of persistence; do not extend it here.
- Nonzero opportunity establishes feasibility only. No contact count, coverage or alpha value is an aesthetic success threshold.
- Existing View 4's fixed phase means B/C requires a newly defined manipulation; do not render a duplicate and call it a test.
