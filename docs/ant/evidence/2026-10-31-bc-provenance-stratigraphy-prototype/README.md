# B/C provenance stratigraphy prototype

Research-only ledger built from the registered B/C shadow maturation events. No world was simulated and no production material, feedback, selector, competition, or commit behavior was changed.

## Result

**COMPLEMENTARY BUT OVERPROLIFIC.** The event histories produce broad, mixed, and channel-exclusive local provenance, with many strict B→C and C→B sequences. The unarbitrated stream crosses the existing 256-Plate storage ceiling reference in every seed between 247 and 273 s, while the production histories create only 23–37 actual Plates per 600 s. This is event-pressure evidence, not a proposal to truncate the event ledger.

The result supports keeping dual provenance as a research direction while leaving a separate final commit/arbitration responsibility unresolved. It does not authorize real Plate creation or different physical/audio properties.

## Scope boundary

B and C differ only by provenance. A virtual layer is exactly one registered event's X mask and timestamp. Exact-time deposits at the same cell are coeval `{B,C}` groups. The ledger has no thickness, physical property, audio behavior, locomotion effect, or production `MaterialStratigraphy` state.
