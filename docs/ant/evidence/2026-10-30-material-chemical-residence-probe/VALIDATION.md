The first deterministic actual material/bare interface verifies the explicitly piecewise 316-to96 nearest lookup. This does not test every grid convention or prove a natural interface law.

The first inventory of quietness covered final touched nodes only. Before promotion, the probe was refined to save source age at each actual prospective local sensor footprint, all 18 native sample points, and positive bilinear support nodes. The 15 s reference is the pre-existing native half-life, not a tuned material threshold. Zero/untouched nodes are excluded from age distributions. Native point kernels reject outside requests consistently; this recorded source stream contains no segment requests requiring a separate clipping interpretation.

Support-coverage fractions are geometric tap/interpolation summaries, not value-weighted chemical fractions or native-response attribution. The restricted old-material fields invoke the native sensor with its true weighting and nonlinear response. Their deltas are mask interventions, not additive author/source contributions.
