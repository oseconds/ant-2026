## Decision and conditional continuation

The probe may establish distinctness/recipient leverage, not a promising full-world mechanism by itself. Stop before a coupled screen if control replay fails, relevant source-free context is unavailable, changes are only an equilibrium gain, downstream recipients collapse the difference, or a material-chemistry meaning must be settled first.

Only if this countermodel has a clear independent temporal responsibility and real unsaturated recipient leverage will one separately registered, independent production-baseline world screen be considered. It would retain production source rate and current 10% locomotion; it would not stack Pass 3 attenuation. No adoption is authorized by this probe.
