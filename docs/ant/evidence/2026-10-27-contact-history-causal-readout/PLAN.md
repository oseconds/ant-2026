Registered 2026-10-27 (Asia/Seoul), before any candidate comparison images were rendered.

## Question

Does persistent evidence placed at actual supported foot-contact locations read differently from visually matched accumulated marks placed elsewhere on the same Plate?

This pass tests a renderer-only archive of post-birth use. It does not represent Plate formation history, literal growth, material phenotype, resonance, or a new simulation law.

## Eligible event source

Observe the production `SurfaceAudioBridge.handleFootContact` route using the same `SurfaceField` per-foot responses and exposed-Plate ownership rules. Read eligibility before its enabled/ready transport gate. Compare a ready recording bridge with a disabled bridge; the disabled bridge must observe the same supported feet and post none. Do not use audio posting/readiness as the visual-history gate.

Store each eligible route's tick and event time, event/group identity, ant, foot/leg, exact response position, event-time Plate ID, physical owner, display owner, and both A/B placement results. Preserve ineligible routes as counts, not marks.

The current-owner visibility rule for either mark is: keep the archive record, but draw only while both the production physical owner at the exact point and canonical display owner at that point equal its event-time Plate ID. Otherwise hide and count it as buried or display-unsupported.

## Registered non-causal placement rule

Use one rigid Plate-local isometry, centered on the centroid of the Plate's immutable 96×96 binary support mask. Do not use random numbers or generate a new point field. This preserves the contact cloud's pairwise geometry while moving individual event marks away from the locations actually contacted.

Before the artist-facing capture, a geometry-only H1 replay selects one transform globally from this fixed ordered set: `rotate-180`, `reflect-x`, `reflect-y`, `rotate-90-cw`, `rotate-90-ccw`, `reflect-diagonal`, `reflect-antidiagonal`. For each eligible source event whose native display owner matches its event-time Plate, the target must also resolve to that Plate under both production 96-grid physical routing and the canonical 640→96 display-owner sampling, and be at least 12 native pixels from the source. Select by highest valid target count, then highest unique valid target pixel count, then fewest source/target same-pixel pairs, then the listed order. This rule uses support and geometric measurements only; no candidate image or visual preference is used.

The relocation rule is valid for capture only if at least 90% of source routes with valid event-time display ownership obtain supported targets at the registered separation. Otherwise stop without an artist comparison and report manipulation-invalid/inconclusive. Invalid individual targets remain archived and counted but do not draw in B. A continues to draw each source route that independently passes its event-time display-support rule; A/B count differences are reported rather than concealed.
