## Reproduction

At the research branch, use Node and installed repository dependencies:

```sh
node --test tests/ant-pheromone-decision-shadow.test.js tests/ant-pheromone-provenance.test.js
node scripts/ant-pheromone-decision-responsibility.js --check
node scripts/ant-pheromone-residual-validity.js --check
```

The two `--check` commands replay the committed frozen packet twice and compare exact summary bytes. They **do not rerun nature**. Each runner uses production methods on cloned state, checks query/tape compatibility and rejects global RNG use during frozen analysis. Without `--check`, acquisition/output commands refuse to overwrite the existing packet or result. To reproduce acquisition, use a separate clean copy with only this package's generated data removed, preserving committed originals; do not delete source evidence in this checkout.

Raw input: [frozen-cases.json.gz](data/frozen-cases.json.gz), SHA-256 `0ddbd5dd622de9cd504f9713c687251a3096bf63a3231cd3dc1cb5c2022a139d`. JSON decoding must revive sole-key `{"$antNegativeZero":true}` objects to IEEE `-0`. Ordinary JSON roundtrips lose that distinction; the runner's codec preserves it.
