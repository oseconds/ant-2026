# Local candidate viewing

The candidate is the code on branch `codex/ant-material-feedback-ad-production-candidate-20261030`.

1. From the repository root, run `npm run dev`.
2. Open the local Vite URL printed by the command.
3. Select **ANT** and confirm the control reads **Audio Off**.
4. Let the current browser world run and inspect the ant/material interaction. Reload to start a fresh local view.

The browser view is not the fixed-seed quantitative replay. For the reproducible comparison, use the saved 20261005, 60 Hz, 600 s treatment and control files in `data/treatment/` and `data/control/`. The saved comparison uses the production 10% control versus this branch's unchanged 10% + A + D candidate.
