# Reproduce the saved-trajectory collective readout

The analyzer uses eight raw JSON captures from prior evidence commit `9fcd96205ff8a5c671be26e2e024524c0e9345d1`. That commit stores their byte-exact gzip packages. No old branch source or world law needs to be merged. If the commit is unavailable locally, fetch `codex/ant-spatial-dynamics-research-20261022` from the existing origin first; remain on the current research branch.

From the repository root, the following PowerShell/Node snippet verifies any existing raw input without overwriting it, or extracts only a missing, hash-qualified input. Paths and compressed/uncompressed byte counts must match both evidence manifests. It does not run a simulation or normalize JSON bytes.

```powershell
@'
import assert from 'node:assert/strict';
import { execFileSync } from 'node:child_process';
import { createHash } from 'node:crypto';
import { existsSync, mkdirSync, readFileSync, writeFileSync } from 'node:fs';
import { dirname } from 'node:path';
import { gunzipSync } from 'node:zlib';
const ref = '9fcd96205ff8a5c671be26e2e024524c0e9345d1';
const prefix = 'docs/ant/evidence/2026-10-22-spatial-dynamics/';
const local = JSON.parse(readFileSync('docs/ant/evidence/2026-10-23-natural-field-transfer/collective/anchor-manifest-v4.json'));
const gitBlob = path => execFileSync('git', ['show', `${ref}:${path}`], { maxBuffer: 128 * 1024 * 1024 });
const packed = JSON.parse(gitBlob(prefix + 'validation/packed-results.json'));
const sha = bytes => createHash('sha256').update(bytes).digest('hex');
for (const input of local.frozenInputs) {
  assert.ok(input.path.startsWith(prefix));
  const receipt = packed.results.find(row => row.raw === input.path.slice(prefix.length));
  assert.ok(receipt);
  assert.equal(receipt.rawSha256, input.sha256);
  assert.equal(receipt.rawBytes, input.byteLength);
  if (existsSync(input.path)) {
    const bytes = readFileSync(input.path);
    assert.equal(bytes.length, input.byteLength);
    assert.equal(sha(bytes), input.sha256, input.path + ': existing raw input differs; preserve and inspect it');
    continue;
  }
  const compressed = gitBlob(prefix + receipt.gzip);
  assert.equal(compressed.length, receipt.gzipBytes);
  assert.equal(sha(compressed), receipt.gzipSha256);
  const raw = gunzipSync(compressed, { maxOutputLength: receipt.rawBytes });
  assert.equal(raw.length, input.byteLength);
  assert.equal(sha(raw), input.sha256);
  mkdirSync(dirname(input.path), { recursive: true });
  writeFileSync(input.path, raw, { flag: 'wx' });
}
console.log('Eight frozen raw inputs verified; no existing input overwritten.');
'@ | node --input-type=module

node tests/ant-transfer-collective.test.js
node scripts/ant-transfer-collective.js --anchors-v4
```

The reproduction command targets the published output paths. Preserve the committed artifacts before invoking it; use an isolated checkout or back up those outputs if comparing regenerated bytes. The original input files must remain unchanged. Source/script/protocol hashes in the v4 manifest distinguish the exact executed version from a later implementation. The Python/Pillow contact-sheet recipe and its separate receipt describe rasterization of the saved SVGs, not a new simulation or an artistic judgment.
