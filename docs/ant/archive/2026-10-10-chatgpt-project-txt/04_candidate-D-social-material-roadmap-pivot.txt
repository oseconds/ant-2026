응. 지금 결과까지 보고 나면 **청사진을 한 번 수정하는 게 맞아 보여.** 원래 청사진의 가장 큰 장기축은

`transient social topology → repeated traffic → persistent material topology`

였는데, S0~S2c 결과 때문에 여기서 **social topology를 독립적인 생성 원인으로 세우는 근거가 약해졌어.** 청사진에서도 Phase C의 질문 자체가 “social graph가 위치/density를 다시 표현한 것 이상인가?”였고, 현재 답은 적어도 선택한 범위에서는 **“뚜렷하게 그렇지는 않다”** 쪽이야. fileciteturn62file6

그래서 나는 ANT의 중심을 오히려 더 단단하게 이렇게 잡는 게 좋아 보여.

```text id="edi4tr"
equal agents
    ↓
movement / collision / hesitation
    ↓
pheromone = chemical memory
    ↓
FOOT_CONTACT = physical action
    ↓
SurfaceField = mechanical memory
    ↓
Plate / stratigraphy = frozen material history
    ↓
physical vibration / sound
```

**이게 이미 ANT의 강한 작품적·시스템적 언어야.**

Social graph는 버리는 게 아니라:

```text id="sfmav9"
movement
  ├─→ environment / material / sound   ← 생성계
  └─→ social topology                 ← 관찰계
```

이렇게 **관찰 도구로 옆에 두는 것**이 맞고. “사회가 물질을 만든다”보다 **“집단의 움직임이 흔적을 만들고, 흔적이 물질이 되고, 물질이 소리를 갖는다”**가 지금 evidence에도 훨씬 정직하고 작품적으로도 더 강해.

### 그래서 당분간 방향은 세 단계가 좋아 보여

**1. 지금 — Material/Sound language 완성**

우리가 방금 멈춘 substrate가 딱 여기야.

현재 Plate가 `구조적으로 형성된 material`이라면 substrate는 그보다 이전의 **미분화된 바닥/입자층**으로 만들면 세계관이 선명해져.

```text id="6d484s"
substrate
dull / sandy / granular / frictional
short, diffuse response

↓ repeated traffic / history

Plate
defined / resonant / structured
clearer modal identity
```

이 대비가 생기면 지금까지 만든 Plate birth가 **소리로도 “재질이 생겼다”는 사건**이 돼.

그래서 다음 실제 구현은 여전히 **substrate sand-timbre pass**가 제일 가치가 커.

---

**2. 그다음 — Material history가 실제로 읽히는지 보기**

여기서는 social graph 대신 **Material graph 자체를 더 읽는 단계**가 좋아.

예를 들어 새 복잡한 기능을 넣는 게 아니라:

```text id="9bdizz"
traffic/contact history
→ SurfaceField
→ Plate birth
→ overlap / burial
→ stratigraphy
```

가 긴 실행에서 실제로 어떤 morphology를 만드는지 관찰하는 거야.

Plate 수만 세는 것보다,

- Plate birth cadence
- exposed ↔ buried 변화
- overlap depth
- active sonic material count
- 오래된 구조와 현재 traffic의 공간적 mismatch

같은 **이미 존재하는 시스템의 역사성**을 읽는 거지.

이건 지금 ANT의 핵심 질문과 직결돼.

> 현재 행동은 사라져도 과거의 행동이 물질로 남는가?

이 질문은 social-role보다 훨씬 잘 살아 있어.

---

**3. 나중 — Closed loop를 열고 싶다면 social feedback보다 material sensing부터**

원 청사진의 후반에는:

`Material → Ant mechanosensing`

이 있었잖아. fileciteturn62file6

나는 지금 결과를 보면 오히려 이쪽이 **다음 큰 연구축 후보**라고 봐.

```text id="e6fw5k"
ants move
→ environment changes
→ material forms
→ material vibrates
→ ants sense material
→ movement changes
```

이건 진짜 폐루프야.

그리고 social graph를 억지로 중간 원인으로 집어넣지 않아도 돼.

```text id="241uqa"
OLD idea

social topology
→ material
→ sound


POSSIBLE revised long-term idea

movement
→ chemical/mechanical memory
→ material
→ vibration
→ sensing
→ movement
```

이게 구조적으로도 훨씬 아름다워.

다만 **mechanosensing은 아직 구현하자는 뜻은 아니야.** 그건 별도 research review부터 해야 돼. 실제 개미 substrate vibration sensing과 지금 Plate 모델 사이에 어디까지 근거가 있는지를 먼저 봐야 하고, 나머지는 artistic interpretation이라고 표시해야 해.

---

그래서 내가 지금 ANT를 다시 청사진으로 압축하면:

```text id="v82qui"
PHASE 1 — GENERATED WORLD               DONE
movement / pheromone / gait

PHASE 2 — MATERIAL VOICE                NOW

PHASE 5 — CLOSED ENVIRONMENT LOOP       ONLY IF JUSTIFIED

```

나는 이 방향이 **원래 프로젝트를 축소한 게 아니라 오히려 중심을 정리한 것** 같아. Social 연구를 꽤 깊게 해봤기 때문에 “social graph가 멋있으니 넣자”를 버릴 근거도 생겼고.

그리고 작은 repo housekeeping 하나 있어. `docs/ant/README.md`는 이미 S2c까지 정확한데, **root `README.md`와 `AGENTS.md` 일부는 아직 “next = movement-constrained null”로 남아 있어.** 다음 구현 전에 그 두 군데를 current roadmap에 맞춰 한 번 갱신하는 게 좋아.

내가 고른 **당장 한 수**는:

**문서 청사진 업데이트 → substrate를 “pre-material granular bed”로 명확히 정의 → sand timbre pass.**

그게 지금 제일 자연스럽다.
