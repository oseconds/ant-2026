# ANT external research reviews

This directory stores external literature syntheses used as research context for ANT.

These documents are not implementation evidence and do not supersede the current code, docs/ant/README.md, dated evidence, or daily records. The original Consensus PDFs remain in the ChatGPT ANT_2026 project sources. The repository keeps Markdown copies so Codex/Astra and ordinary Git tooling can search, diff, quote, and review the literature without depending on binary PDF access.
