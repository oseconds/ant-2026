## 3. Complete-state null and what Plate-native can already retain

For a probe boundary, relevant state includes the ordered frozen descriptors, thickness/exposure and compiled node/link arrays; all relevant environmental arrays, sampler/filter clocks and pending agent inputs; nodule descriptors/state if present; and solver current/previous values, awake/quiet/pending-wake state, contact pulse rings, local recovery memory, step clocks and output queues. Include bridge enabled/loading state, routing, generation and message ordering when using the bridge. A few field scalars or an equal q mask are not this state.

There are two comparisons with different responsibilities:

1. **Layer-presence ablation:** clone the complete existing world. Treatment appends only the proposed layer; control keeps all prior Plates and omits that one layer. Match future modeled input and its actual old-layer target. Different resulting descriptors/topology are the deliberate retained difference. This can test an added-layer consequence, not the need for hidden constitutive state.
2. **Existing-Plate explanatory null:** initialize a replay with the treatment's complete resulting descriptors, topology and solver state, then give it the same future input without any formation label/history-score adapter. It must predict the same response. If it does, the proposed response needs no additional Material variable. Matching every relevant state and then expecting a different deterministic response is a contradiction, not an ontology discriminator.

Supply/event provenance may reconstruct a consumed-item set for a proposed arrival rule. That is new formation bookkeeping, not a new constitutive field. Putting a new predictive variable inside a Plate instead of a Material class would still add state. Conversely, storing an immutable new Plate is already a retained physical configuration, even if its material coefficients are fixed. Derived Deposit remains sufficient for the resulting layered relations.

## 4. One conditional contract: supplied-lamina arrival

### Operational event and declared inputs

Call the restricted proposal **PN-arrival-0**. It models attachment/installation of a supplied lamina into the sounding world. It does not claim that a foot manufactures matter, that memory is consumed as matter, or that cohesion emerges from activity adjacency.

Before execution, declare one finite configuration packet `s`: a unique supply ID; an immutable nonempty 96×96 world-space mask, edges and pickups; explicit positive thickness if depth is part of the claim; and one fixed shared stiffness/density/damping triplet within current compiler ranges. Placement/orientation are part of the supplied configuration, not selected afterward from an attractive route. A packet denotes a bounded configured layer, not a measured mass. Finite one-item availability is this comparator's boundary, not evidence that ANT must have a finite precursor reservoir.

Declare one individual contact key `e` (raw row + foot ordinal for archived data; equivalent deterministic key for a synthetic fixture), its point/time, and a named joint-memory checkpoint at that same time immediately before this event's field update. The point must lie in both the supplied mask and the supported mask returned by the pinned production sampler at that checkpoint. This uses the existing ≥0.30 chemical-memory and ≥0.015 sampled-support qualification as an **assumed activation condition**, not calibrated formation physics. Disclose sampler/filter state and sampling semantics; no stale/interpolated qualification, binary-bit substitution for unavailable fields or inferred mechanical work is allowed. Synthetic initialization would be a declared input, not reconstructed formation history. The solver-only feasibility/next comparator below does not execute this activation rule.

The sole proposed new causal link is: **a declared qualified contact opportunity attaches one available supplied configuration once**. Contact is a trigger. Supply, primitive within-lamina mechanics and the placement rule are explicit author inputs. The new law is not the old `TrailPlateBirth` event with a formation label attached.

This defines an executable family once its explicit packet/event/checkpoint inputs are supplied. It is a constructive answer to the storage objection: Plate-native retention does not require an independent material field. It deliberately does **not** derive packet amount, footprint, primitive cohesion or material constants from ANT history. It does not fulfill the artistic aim of material forming from individual activity and shared history during an organism's living episode. Those missing mappings prevent promotion of PN-arrival-0 to an endogenous formation law; local formation during ongoing activity remains allowed, as the earlier gate states.

### Restricted insertion and response

The restricted contract inserts only at a prescribed **zero-vibration boundary**: old/new current and previous values zero; `awake`, `energyQuiet`, `pendingWake`, `activeCount` and `pendingCount` zero; no nodule motion, pending pulse input, recovery residue or queued output. All old IDs and solver grid indices remain identical. The activation opportunity is recorded separately and is not replayed as an unaccounted strike. A later single modeled probe supplies input to the same old exposed region in both worlds.

This is a synthetic intervention, not an assertion that natural contact-triggered births occur at rest or that controller/audio clocks already support this ordering. Current controller contact handling occurs before scheduled birth. Live contact-driven insertion, deferred attachment and asynchronous transaction ordering are outside the restricted contract; choosing any requires a separately stated transition rather than silently changing the rest fixture.

The independently specified **modeled physical observable** is an inherited Plate's raw nodal displacement trace under that later probe, with an added-layer trace as a secondary record. Neither formation labels, descriptor count, display geometry, final stereo mix, nor direct reading of an invented character score is acceptance evidence. The existing-state replay must explain the trace without the arrival label. Such response independence from the label does not mean empirical independence from the assumed solver.

## 5. Loading, units and insertion work

| Quantity/boundary | Allowed interpretation | Limit |
| --- | --- | --- |
| Contact event and SurfaceField | 2D activity plus normalized activation/dose inputs | `strength` is deterministic gait strength; SurfaceField ignores it. Neither supplies normal force, pressure, indentation or work |
| Probe control | Same declared worklet strike payload to the same old Plate/region, including identical finite pulse-ring increments before stepping | Modeled excitation, not measured foot loading or prescribed displacement. Do not demand equal reaction as an extra input |
| Coordinates/time | Normalized XY; exact source/solver grids; 6,000 Hz physics and source pulse/recovery conventions | No demonstrated XY-meters or displacement-meters calibration. Named thickness meters do not calibrate Plate stiffness or node mass |
| Coefficients | Compiler maps stiffness/density/damping to its current normalized update; use fixed shared values | Thickness is not an input to ordinary Plate bending/density coefficients. A thickness/mass or consolidation law would require new assumptions |
| Boundary | Existing mask stencil and current local overlap springs; no nodules/base substrate for the first fixture | Do not substitute standalone circular Plate or claim solved unilateral foot contact |
| Diagnostics | Raw displacement and exact compiled/pulse arrays; telemetry only for diagnosing stepping/sleep/drop/nonfinite behavior | `energyDelta`, `couplingWorkProxy` and squared impulses are not calibrated mechanical energy/work |

The worklet's old-state preservation is conditional on ID and exact solver geometry. It copies current/previous, contact forces/recovery and quiet counters, then restores formerly awake nodes through `wakeNode`, which resets their `energyQuiet` to zero. Awake membership is restored; an active quiet timer is not preserved. A changed geometry can reset that layer. Hence a response difference after recompilation must be checked against an identical-topology reinstall control, not assumed to come from new material. The restricted all-zero/rest boundary avoids this specific quiet-timer change; it does not solve arbitrary live-state insertion.

There is also a specific **live-insertion counterexample**, derived rather than experimentally measured here. For a reciprocal linear link with coefficient `kappa > 0` and generalized displacement difference `d`, the potential consistent with its instantaneous force is `U_link = kappa*d²/2`. Appending a new zero-state layer to an old displaced layer introduces new-link potential `Delta U_link = sum(kappa*q_old²/2)` wherever new links form. Retaining old node values does not make this transition energy-neutral. An existing top layer's links below remain, and the new links add a term. At all-zero displacement this particular jump is zero; at nonzero displacement it can be positive even before a new foot pulse.

This is a normalized spring interpretation and a boundary-accounting warning, not a proof of the full discrete solver's energy conservation or SI work. The force/potential convention and physical-unit caution follow standard [MIT harmonic-oscillation notes, §§1.2 and 1.7](https://ocw.mit.edu/courses/8-03sc-physics-iii-vibrations-and-waves-fall-2016/8eb46d081c5ba4728cbbb369a03ba45e_MIT8_03SCF16_Text_Ch1.pdf); applying it to the source's new links is our derivation. The restricted rest boundary avoids this immediate term. It does not supply chemical/binding/rest energy or justify deposition during live vibration. A later mechanical arrival law would have to name its external formation work, initial/reference configuration and any dissipated energy, or disclose nonconservative authored insertion. Mass conservation is not mandatory for every artistic model; claims of mass/work conservation require their own account.

The signed displacement-controlled `p` witness remains [standalone mathematics](w1-material-response-discrimination-design.md). It supplies no activation, layer creation or compatible ANT loading for this contract. No plasticity, anisotropy or sonic preset is adopted.

Further controls matter: no input gives no motion; a disjoint new layer cannot influence the old layer through absent Z links; a top-overlap strike changes the input target; a pickup at a node of the response can miss a real transfer; sleep truncation, pending input or reinstalls can change traces; at rest, added DOFs can be silent; constant-coefficient laminae can change composite response without acquiring different intrinsic characters. Beautiful geometry, many types and biological realism are not acceptance conditions.

The priority contract's principal limitation is therefore exposed rather than hidden: an externally supplied configuration makes creation decidable. Present ANT records do not provide that configuration/supply channel or select a contact-to-configuration conversion law. This is a modeling choice to investigate, not missing storage that automatically requires a Material field.

## 7. Decision and unresolved gates

**Existing-state sufficiency:** the current Plate descriptor, topology and dynamic state can explain the proposed added-layer vibration response. Do not add a Material field merely to preserve that response or move the same data to another class.

**Conditional operational specification:** PN-arrival-0 is operationally specifiable as a supplied, rest-inserted lamina attachment law. Its declared inputs close event, retained increment, provenance, reset and modeled probe semantics. This is not production adoption or proof of a natural formation process. The rest restriction and supplied primitive body are substantive assumptions.

**Undecided / Research Gap for the ANT formation question:** the contract is not closed for endogenous, repeated formation from individual activity and environmental memory. The missing conditions are concrete:

1. A justified or explicitly chosen channel from activity/memory to an available configuration/increment. Neither locality nor persistence identifies it; exogenous arrival and endogenous conversion are different hypotheses.
2. Spatial extent, contribution/repeat identity and birth partition that do not arise solely from arbitrary scheduler/grouping decisions. Unique provenance does not imply conservation, and shared effects are possible if declared.
3. A live transition boundary: formation/attachment state, initial/reference geometry, current oscillation, external work or disclosed nonconservative insertion, and contact-versus-topology message order.
4. If a mechanical/constitutive formation interpretation is intended, compatible load control, units, geometry and response rather than a dose→force relabeling. If an artistic arrival law is intended instead, its externally supplied assumptions must be accepted as assumptions.
5. Any claimed intrinsic Character needs its own constitutive prediction. Added-layer geometry/exposure effects currently establish conditions, not a new intrinsic consolidation/direction property.

No current independent response establishes a **requirement for additional material state or retained relation**. A later bond/slip/configuration law might require extra state, whether stored in Plates or a field. It must first specify a response that the complete existing-Plate null cannot predict. Existing archives cannot reveal an unimplemented hidden physical process by themselves.

A determinism replay disagreement exposes an omitted state/input or harness fault; audit that gap before introducing any Material state. A control difference, failed state/input match, nonfinite/drop event or missing link/reachability makes the comparison unaccepted/typed Inconclusive. Stop and preserve that result; do not move the probe, extend the horizon, vary coefficients or tune morphology to manufacture a positive outcome.

Exact replay/control parity is a deterministic requirement. Pin the source's IEEE arithmetic and save Float32 traces. For the first inherited-node divergence, independently reconstruct the local update from the shared pre-step old state, treatment new-node state and packed link coefficients; compare the extra Z term with interval bounds for the binary64 operations and final Float32 rounding. If the sign/nonzero change cannot be separated from those bounds, report typed arithmetic Inconclusive; do not pick a preferred audible/visual threshold. This is a local attribution check, not a global stability/energy proof. A mathematically expected difference is still a solver consistency prediction, not empirical formation falsification. A passed comparator supports only the authored model's representation/response compatibility and the existing-state explanation. Finish this one finite comparator and stop. A next formation pass, if pursued, must choose and disclose one arrival or conversion channel and its live transition contract; it must not automatically add Material/Deposit state, vitality, steering, social feedback or acoustic climate. If the narrow solver consequence is already sufficient for the intended design claim, skip this optional attribution pass and retain the endogenous gap.
