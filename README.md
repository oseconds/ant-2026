# 시뮬레이션 페이지

- `html/index.html`: 시뮬레이션 목록 페이지입니다.
- `html/strange-string/`, `html/karplus-strong/`, `html/circular-plate/`, `html/steel-sphere/`: 각각 HTML 하나를 둡니다. 원형 판과 구 페이지는 필요한 AudioWorklet JS도 같은 폴더에 둡니다.
- `.vscode/settings.json`: Live Server의 웹 루트를 `html/`로 지정합니다.

VS Code에서 프로젝트 폴더를 열고 **Go Live**를 누르면 페이지 목록이 열립니다. 목록에서 원하는 시뮬레이션을 선택하세요. 각 시뮬레이션 HTML을 직접 열어 Live Server로 실행해도 됩니다.
